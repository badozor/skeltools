# skeltools 0.1.0

* Premiere version.
* `create_project()` : template de base (`data/`, `archive/`, `tmp/`, `src/R/`)
  avec couches optionnelles Python et C/C++.
* `list_layers()` : liste des couches disponibles.
* Template RStudio (File > New Project).
* Depot organise en `trunk/` : sources du package (`trunk/skeltools`),
  manuel PDF (`trunk/documentation`), archives (`trunk/Rpackage`).
